Next.js 제품 Build 후보입니다. 실제 Script, 산출물과 렌더링 방식은 package.json, Next.js 설정과 배포 방식이 확정된 뒤 확인합니다.

Development

npm run dev (후보)

Next.js 개발 서버를 사용하는 일반적인 예시입니다. Flutter 기기와 에뮬레이터의 개발 서버 접근 주소와 연결 방식은 환경별로 확정합니다.

Storybook

npm run storybook
npm run build-storybook

Storybook 개발 화면과 정적 Build의 일반적인 예시입니다. 실제 Script와 Builder는 package.json과 Storybook 설정에서 확인합니다.

배포 시나리오

정적 후보: output: "export" 설정 → next build → CDN
서버 후보: next build → next start
WebView: 승인된 HTTPS 배포 주소 로드

정적 배포와 서버 배포는 서로 이어지는 단계가 아닌 대안입니다. 배포 플랫폼, 렌더링 방식과 Native 앱 연계 범위는 모두 TBD입니다.
