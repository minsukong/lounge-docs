배포

Production Build

npm run build

Next.js production build. 출력: .next/ (chunks, static assets, HTML). SSG 라우트는 정적 HTML로, 동적 라우트는 SSR 런타임으로 분리.

Quality Gate (병렬)

npm run typecheck
npm run lint
npm run test
npm run build-storybook

모두 통과해야 production build가 실행됩니다. CI 파이프라인에서 순차 게이트로 운영.

Development

npm run dev

Turbopack 기반 dev server (Next.js 16 default). HMR, on-demand compilation. WebView 개발 중에는 http://localhost:3000에서 로드.

Storybook

npm run storybook
npm run build-storybook

dev: Vite dev server로 스토리 뷰어. build: storybook-static/ 정적 출력. QA/디자이너가 독립적으로 UI 검증.

배포 시나리오

정적: next build --outdir out → CDN
동적: next start (Node.js 서버)
WebView: Flutter → localhost:3000

WebView 프론트엔드는 Flutter 네이티브 앱이 WebView를 통해 로컬/리모트 URL에서 로드합니다.
