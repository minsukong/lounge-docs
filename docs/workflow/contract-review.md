## API 검토

| 항목 | 확인할 내용 | 결과·질문 |
| --- | --- | --- |
| 동작·입출력 | 승인된 요청·응답, 필수/선택/null, enum, 검증, 필드 의미 | |
| 목록·수치 | 페이지·정렬, 금액·시간·단위·시간대의 의미가 필요한 경우 | |
| 인증·권한 | 실제 세션 방식, 권한·만료·재인증, FE/BE/Native 책임 | |
| 실패 | 업무 오류·인증 오류·전송 실패와 UI 처리의 구분 | |
| 재시도·중복 | 변경 요청의 중복 제출·재시도 허용 조건. 결제는 상태 조회 포함 | |
| 캐시 | Query key·갱신·무효화·사용자 전환·로그아웃 때 데이터 처리 | |
| 호환 | 버전·기존 소비자·변경 영향·배포 순서 | |
| 검증 데이터 | Backend 재현 범위, mock 필요 시 합의·관리자·계약 버전 | |

API 문서에 없는 endpoint·응답 스키마를 검토자가 만들어 확정하지 않습니다. API 합의가 있어도 운영 정책·Bridge 차단이 남으면 전체 연동 Ready가 아닙니다.

## Bridge 검토

| 항목 | 확인할 내용 | 결과·질문 |
| --- | --- | --- |
| 책임 | Web·Flutter 중 시작·실행·완료·사용자 오류 안내의 담당 | |
| 메시지 | 합의된 명령·payload·버전과 응답·이벤트의 의미 | |
| 수명 주기 | 준비 전 호출, 요청/응답 연결, timeout·취소·중복 callback | |
| 이동 | Native/Web 뒤로가기, 외부 앱·브라우저·딥링크·복귀의 실제 흐름 | |
| 권한 | 허용·거부·제한·설정 변경 후 복귀 중 적용 상태 | |
| 인증 | 세션 전달·갱신·로그아웃 책임과 민감정보 저장·로그 경계 | |
| 플랫폼 | Android/iOS 차이, 웹 브라우저에서 해당 기능의 동작 또는 제외 | |
| 검증 | 지원 기기·OS·앱 버전과 실제 재현 결과 | |

합의되지 않은 command 이름·전역 객체·token 전달 방식·fallback을 만들지 않습니다. Android/iOS 차이는 실제 계약과 기존 adapter에서 확인하며 화면에 플랫폼 객체를 직접 노출하지 않습니다.
