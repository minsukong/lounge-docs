# workflow 스크립트 안내

실행은 실제 목적이 있을 때만 합니다. 문서 읽기 요청에서 자동 실행하지 않습니다. Python 표준 라이브러리만 사용하며 특정 AI 도구의 런타임을 요구하지 않습니다.

| 목적 | 파일 | 쓰기 범위 |
| --- | --- | --- |
| IA 원본 ID 대조 갱신 | refresh_ia.py | ia-inventory.csv와 ia-audit.md만 |
| 링크·메타데이터·IA 해시 검사 | validate_workflow.py | 읽기만 |
| 선택한 위치에 공용 스킬 내보내기 | export_skills.py | 미리보기 기본. --apply일 때 대상 스킬과 문서 연결 설정·관리 기록 |

## 실행 기준

문서 저장소 루트에서 python docs/workflow/scripts/validate_workflow.py로 확인합니다. IA를 갱신했을 때만 refresh_ia.py를 실행합니다.

내보내기는 [도구 연결 안내](../agent-adapters.md)의 실제 경로를 넣어 먼저 미리보기합니다. --apply는 사용자가 내보내기·설치를 요청한 범위에서 사용합니다.

원본 IA·제품 코드·글로벌 설정은 변경하지 않습니다. 기존의 다른 파일이나 사용자가 수정한 복사본은 덮어쓰지 않습니다. exporter가 작성한 관리 기록과 해시가 일치할 때만 이전 내보내기본을 갱신합니다.

스크립트 변경 시 구문뿐 아니라 미리보기 무쓰기·재실행·사용자 변경 충돌 차단·원본/복사본 일치를 검증합니다. 임시 테스트 위치의 절대 경로를 확인하고 불필요한 재귀 삭제를 하지 않습니다.
