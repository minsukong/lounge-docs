03 · DOCS LAYERS

AI는 작업별 요약에서 시작해
필요한 구현 예시와 상세 가이드를 확인해 구현합니다.

AGENTS.md, apps/app-webview/작업 규칙과 현재 구현 확인
루트와 앱의 AGENTS.md를 읽고 Package, 설정과 기존 Source를 확인
↓ 작업 종류에 맞는 요약 문서를 선택
docs/ai/AI가 먼저 읽는 작업별 요약
현재 작업에 적용할 핵심 기준과 추가로 확인할 문서를 안내
↓ 구현에 필요한 정보의 깊이를 판단
docs/common-source/*.md공통 설정과 코드의 파일 단위 구현 예시
더 자세한 기준이 필요하면 docs/guides/*.html에서 배경과 적용 범위를 확인
↓ 확인한 기준을 기존 구현에 맞춰 적용
apps/app-webview/실제 Source · Story · Test
구현 결과를 Story, Typecheck, Lint, Test와 Build로 검증

구현과 검증 결과를 남깁니다.

INPUT작업 요청·Figma화면 목적, 사용자 동작과 작업 범위
1 · ROUTEAGENTS 확인저장소 원칙과 앱 지침에서 작업 범위를 확인

OUTPUT → apps/app-webview 구현· Storybook· Typecheck· Lint· Test· Build· 완료 보고
