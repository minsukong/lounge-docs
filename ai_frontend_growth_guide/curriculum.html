AI 협업 Front-End 교육 과정

JavaScript 기초부터 실제 기능 통합과 리뷰까지 순서대로 학습합니다.

1. 과정 사용 방법

이 과정은 모든 코드를 직접 입력하는 교육이 아닙니다. AI가 조사와 구현을 수행하고, 개발자는 요구·상태·계약을 결정하며 결과를 검증하는 방식으로 진행합니다. 협업 원칙은 AI 협업 기반 Front-End 성장 가이드를 따릅니다.

각 단계의 완료 기준을 설명하고 적용할 수 있을 때 다음 문서로 이동합니다. 읽은 문서 수나 학습 시간만으로 완료를 판단하지 않습니다.

2. 기초 언어

  1. JavaScript 기초 — React와 TypeScript에 필요한 값, 함수, 배열과 비동기 처리
  2. TypeScript 기본 — 추론, 객체 타입, Union과 Narrowing
  3. TypeScript 경계 — Props, 외부 입력, API와 Bridge 값 검증

이 구간을 마치면 AI가 만든 타입의 역할과 타입 오류의 원인을 설명할 수 있어야 합니다.

3. React와 화면 구현

  1. React 컴포넌트와 상태 — 책임, Props, State와 소유자
  2. React Effect와 폼 — Event·Effect 구분과 입력 흐름
  3. Next.js App Router — Route, Layout과 Server·Client 경계
  4. Tailwind UI와 접근성 — 토큰, 반응형, 의미 있는 HTML과 Focus

이 구간을 마치면 화면을 시각적 레이어가 아니라 사용자 동작과 상태의 조합으로 설계할 수 있어야 합니다.

4. 실제 서비스 연결

  1. API 계약과 오류 — Backend 계약, 비동기 요청과 오류 분류
  2. 서버·클라이언트 상태 — TanStack Query, 지역 상태와 Zustand 선택
  3. WebView Bridge와 보안 — Native 경계, 인증과 민감정보 보호

이 구간을 마치면 Backend·App 담당자에게 필요한 계약 질문을 하고 미확정 내용을 코드에서 분리할 수 있어야 합니다.

5. 품질과 독립적인 판단

  1. 테스트와 디버깅 — 위험 기반 테스트와 오류 원인 추적
  2. 기능 통합과 리뷰 — 하나의 기능을 계약부터 검증까지 완성

마지막 구간에서는 AI의 구현을 그대로 승인하지 않고 위험과 변경 영향을 검토해 병합 여부를 판단합니다.

6. 공통 완료 기준

  • 핵심 개념을 자신의 말로 설명할 수 있습니다.
  • AI가 만든 코드에서 해당 단계의 위험을 찾을 수 있습니다.
  • Lounge 프로젝트의 작은 기능에 적용할 수 있습니다.
  • 확인된 기준과 미확정 계약을 구분할 수 있습니다.
  • 실행한 검사와 직접 확인한 항목을 구분해 설명할 수 있습니다.
