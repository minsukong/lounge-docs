## 1. 목적과 읽는 방법

현재 기획만 전달받은 작업자가 추가 질문 없이 동일한 결과를 만들 수 있는지 확인한다. 완성된 기획 심사가 아니라, 작업 결과·범위·연결에 영향을 주는 확인 지점을 찾는다.

**Backend 협의 전제(2026-10-07 사용자 확인):** Backend 협의가 충분히 이루어지지 않은 상태. 사용자 정책·흐름은 **기획 확인**, 요청·응답·인증·오류·세션·처리 주체는 **Backend 협의 필요**로 구분한다.

**원본 대조:** Figma REST API depth=9 텍스트 추출 완료. Table 노드(이용권 상태 용어 정리, 주문 상태 용어 정리)는 TABLE 타입이라 텍스트 추출 불가. 정보수정 섹션의 Content Area·영문성명 노드는 추출 결과에 미포함. 이 두 영역은 **독립 재검증 전**이다.
