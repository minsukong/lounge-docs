## 1. 목적과 읽는 방법

현재 기획만 전달받은 작업자가 추가 질문 없이 동일한 결과를 만들 수 있는지 확인하기 위한 기록이다. 기획자 평가나 책임 판단을 목적으로 하지 않는다.

**Backend 협의 전제(2026-10-07 사용자 확인):** 현재 Backend 협의가 충분히 이루어지지 않아 연동 기준의 합의 여부를 확인해야 하는 상태다. 사용자에게 보이는 조건·흐름은 **기획 확인**, 데이터·인증·오류·상태 전달·처리 주체는 **Backend 협의 필요**로 구분한다. API·문서·구현 부재나 모든 항목의 미합의를 뜻하지 않으며, 기존 자료·합의 근거를 항목별로 확인한다.

RC-01-004·005·006의 오프라인·BO 관리 데이터·알림 연결은 기획 요구와 Backend·앱 전달 계약을 나눠 확인한다. 협의 결과에 따라 웹·앱 연동·검증 범위가 달라질 수 있으며, 실제 작업 중단·재작업 여부는 별도 확인한다.

**03 문서와 다른 점.** 03의 후보는 검토용 복제본 기반이라 원본 대조가 되지 않은 상태였다. 이 문서는 실제 원본을 REST API로 읽어 텍스트를 추출한 뒤 작성했으므로, 아래 관찰은 **원본에서 확인한 내용**이다. 각 항목에는 원본 프레임 ID를 붙였다.

원본 대조 완료 표시는 로컬 LLM의 초안 작성 보고를 기준으로 한다. 이번 문서 검수에서는 원본 추출 자료를 확인하지 못해 Figma 관찰 자체를 독립적으로 재검증하지 않았다. 문서의 논리·참조·영향 표현을 수정했으며, 정책이 확정된 것은 아니다.

다만 "이 페이지에 없다"를 "프로젝트 전체에서 미정의"로 확대하지는 않는다. BO 화면 설계, API 명세, 다른 페이지에 정의가 있을 수 있다.

## 3. 검수 분류와 상태

| 분류 | 확인할 내용 |

### RC-01-011 · 공통 오류 정의 위치와 내부 참조 보완
