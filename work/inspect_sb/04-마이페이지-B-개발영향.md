## 1. 읽는 방법

A의 초안 보고 기반 후보에 대해 답에 따라 달라질 웹·앱 작업을 기록한다. 이번 검수는 A/B 문서 논리·참조만 확인했으며 원본·IA·실제 구현 상태는 독립 재검증 전이다. 실제 작업 중단·재작업 발생을 뜻하지 않는다.

Backend 협의가 충분히 이루어지지 않은 상태(2026-10-07 사용자 확인)다. 노출·환불·할인·쿠폰 반환 기준은 기획 확인, 합의된 기준의 계산 결과·상태·오류·처리 주체 전달은 Backend·앱 협의로 구분한다. API·문서 부재나 모든 항목의 미합의를 단정하지 않는다. 승인된 임시 가정은 없다.

APP 하이브리드 앱(Native·앱 내부 WebView)과 WEB 반응형 홈페이지는 별도 과업이다. PC/MO 화면명만으로 플랫폼 배치·구현 담당을 확정하지 않고, IA 시트+코드와 Figma 대응을 확인한다.

## 2. RC별 영향

### RC-04-001 이용권·주문 상태표 내용 미확인

| 영향 대상 | 확인 결과에 따라 달라질 내용 |
|---|---|
| 이용권·주문 탭 | 상태표에 정의된 탭 포함 기준과 실제 상태 전달의 대응 |
| 상세 화면 | 상태별 버튼·표시·이력의 기존 정의와 적용 범위 |
| 연동·검증 | 합의된 전환 조건·상태값·오류·갱신과 기대 결과 |

**현재 상태:** 상태표는 존재한다고 보고됐으나 내용을 읽지 못했다. 표·PDF 확인 후 남는 정책 질문과 Backend 계약 질문을 나눈다. 추출 실패를 표 부재나 전체 구현·테스트 불가로 판단하지 않는다.
