가이드 검색

Lounge의 주요 가이드를 문서명, 목차와 본문 내용으로 검색합니다.

1. 검색

작성용 템플릿과 복제 문서를 제외한 Lounge의 전체 주요 가이드를 문서명, 목차와 본문 내용으로 검색합니다.

두 글자 이상 입력하면 문서명, 목차, 설명과 키워드를 검색합니다.

추천 검색어

검색어를 입력하거나 추천 검색어를 선택하세요.

2. 검색 색인 갱신

가이드 HTML을 추가·수정·삭제한 뒤에는 lounge-docs 루트에서 다음 명령을 실행합니다. 

node .\search\build-search-index.mjs

생성기는 검색 대상 폴더의 HTML을 읽어 문서명, 목차와 본문을 다시 수집하고 assets/js/search-data.js를 갱신합니다. 완료 메시지의 HTML 파일 수와 목차 수를 확인한 뒤 검색 페이지에서 변경한 용어가 검색되는지 확인합니다.

search-data.js를 직접 수정하지 않습니다. 검색 대상 폴더를 바꾸려면 build-search-index.mjs의 guideDirectories 목록을 수정한 뒤 색인을 다시 생성합니다.
