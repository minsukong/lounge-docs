# app-webview

WebView에서 실행될 Front-end 애플리케이션의 위치입니다.

현재는 실제 프로젝트 초기화 전의 빈 골격입니다. package, Next.js App Router, Tailwind CSS, shadcn/ui, Storybook과 Vitest 설정은 구현을 시작할 때 설치된 버전과 가이드를 확인하며 생성합니다. 존재하지 않는 API·인증·Bridge 계약이나 업무 화면은 미리 만들지 않습니다.

## 예정된 영역

```text
app-webview/
├── AGENTS.md
├── README.md
├── .storybook/
└── src/
    ├── app/
    ├── components/ui/
    ├── features/
    ├── lib/
    └── test/
```

빈 디렉터리는 구조를 Git에서 유지하기 위한 `.gitkeep`만 포함합니다.
