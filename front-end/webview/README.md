# webview

Flutter 하이브리드 앱에서 WebView로 실행되는 웹 화면입니다.

이 폴더는 참고 골격이며, 실제 웹 애플리케이션의 package, 설정과 source는 별도 저장소에서 관리합니다. 구현 기준을 참고할 때는 실제 저장소의 설치 버전, 기존 source와 저장소 가이드를 확인하며, 존재하지 않는 API·인증·Bridge 계약이나 업무 화면을 추측하지 않습니다.
