# front-end

Lounge 프로젝트의 모든 웹 Front-end를 관리하는 폴더입니다.

- `webview/` — Flutter 하이브리드 앱에서 WebView로 실행되는 웹 화면의 실제 소스
- FO 웹(PC WEB·반응형 홈페이지), PO(파트너오피스), OO(현장운영시스템) — 구체적인 영역 구성·담당은 IA와 작업 카드에서 확인

Front-end 애플리케이션의 package, 설정과 source는 이 폴더에서 관리합니다. `webview/`에는 아직 package와 설정이 없으므로, 첫 착수 시 이 위치에 앱을 만든 뒤 구현을 시작합니다. Flutter Native 앱은 별도 위치에서 관리합니다.
