# 최소 문서 확인 규칙

- 먼저 가장 가까운 `AGENTS.md`와 사용자가 지정한 파일 또는 실제 Source만 확인합니다.
- 문서 안의 링크를 따라 브리핑이나 관련 가이드를 연쇄적으로 읽지 않습니다.
- `.clineignore`의 파일은 일반 질문과 구현 작업에서 읽지 않아도 되는 기본 제외 자료입니다.
- 사용자가 파일을 직접 지정했거나 해당 문서 자체의 작성·검토·이관·검색 작업일 때만 제외 자료를 읽습니다.
- 구현 기준이 더 필요하면 작업 종류와 직접 일치하는 `docs/ai` 요약 하나를 먼저 확인하고, 그 요약으로 판단할 수 없을 때만 상세 가이드나 `common-source` 문서를 추가합니다.
- 같은 내용의 Markdown과 HTML이 함께 있으면 Markdown만 읽습니다.
- 브리핑, 교육 자료, 변경 기록, 초안과 작업자용 일정은 일반 구현의 근거로 사용하지 않습니다.
