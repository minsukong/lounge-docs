# Guide Changelog Updates

- When creating, updating, moving, or removing a guide under `docs/`, update `docs/CHANGELOG.md` in the same task.
- Add the new entry under the latest date, following the existing changelog format and keeping the newest entries first.
- Record the purpose, major changes, unresolved items, and verification results instead of listing only changed files.
- If Markdown and HTML versions of the same guide are changed together, record them as one changelog entry.
- Do not consider a guide-writing task complete until the corresponding changelog entry has been added.
